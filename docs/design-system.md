# 设计规范

更新日期：2026-10-22
视觉方向：Editorial 编辑杂志风，基于已选定的 G 版。

## 设计方向

用户已选择 Editorial 作为整个组件库的最终风格。以暖米色底、柔黑文字、衬线标题、无衬线正文、细分隔线和适度留白建立秩序；主操作采用柔黑实底，表单以下划线为主。单色信息架构贯穿基础组件、复杂表格、树、日期、上传、浮层和文档。

[选定设计稿与来源](design-exploration/2026-10-22-stylekit-editorial/README.md)提供视觉锚点，[决策记录 0003](decisions/0003-editorial-visual-direction.md)记录选择。正式规则以本文为准，生成图中的字形、微小纹理、字重、文案和示例日期不作为实现数值来源。其他候选仅保留为历史比较。

本次确定的是视觉方向与文档基线。下列尺寸及色值是根据选定方向制定的实施基线，并非用户逐项确认的测量值；工程预览中可依据可读性、内容和交互证据校准，并同步本文。当前没有变量源码、组件实现或浏览器验收。

根目录 `DESIGN.md` 继续链接到本文，供 Impeccable 读取。产品事实见[产品定位](product.md)，工程与任务状态分别见[工程约定](engineering.md)和 [roadmap](roadmap.md)。

## 固定的视觉约束

| 维度 | 正式约定 |
| --- | --- |
| 色彩 | 暖米色与柔黑构成单色系统；主操作、选择、焦点均使用墨色角色 |
| 排版 | 页面及分区标题采用衬线；正文、表格、标签、按钮与输入采用系统无衬线 |
| 形状 | 按钮、输入、面板、弹层使用直角；圆形仅用于单选、状态点、头像和开关等有用途的形状 |
| 组织 | 以留白、对齐和细线分区，避免卡片套卡片；后台保留工作密度 |
| 边界 | 结构线细而克制；交互边界、错误和焦点必须清晰 |
| 材质 | 平整实色，无纸纹、渐变、玻璃模糊、浮雕或装饰投影 |
| 状态 | 图标、文案、线条和明暗共同表达；成功、警告、错误仍是不同语义角色 |
| 延展 | 高级组件和后续暗色使用同一套排版、几何与语义；不拼接其他候选的蓝色、粉彩或玻璃风格 |

## Colors

以下为 Editorial 浅色基线。角色名用于后续变量映射，不代表已有导出 API。必要信息和操作不能使用禁用文字色或仅靠结构线识别。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| `color.bg.canvas` | `#F9F8F6` | 页面与默认工作区 |
| `color.bg.surface` | `#FCFBF9` | 需要轻微区分的弹层、输入或内容表面 |
| `color.bg.subtle` | `#F1EFEB` | 次级区域、悬停背景 |
| `color.bg.selected` | `#EEEAE4` | 选中行、当前导航或节点的辅助底色 |
| `color.text.primary` | `#1C1C1C` | 正文、标题、关键状态 |
| `color.text.secondary` | `#595650` | 辅助说明与元数据 |
| `color.text.placeholder` | `#77736B` | 占位提示，不替代持久标签 |
| `color.text.disabled` | `#9B968D` | 不可用控件的文字与图标 |
| `color.bg.disabled` | `#EAE7E1` | 禁用实底控件 |
| `color.border.subtle` | `#D8D3CB` | 非交互结构分隔线 |
| `color.border.control` | `#858077` | 输入下划线、轮廓按钮及交互边界 |
| `color.action.primary` | `#1C1C1C` | 主按钮、勾选、选中日期 |
| `color.action.hover` | `#34312E` | 主操作悬停 |
| `color.action.pressed` | `#111111` | 主操作按下 |
| `color.text.onAction` | `#F9F8F6` | 墨色主操作上的文字和图标 |
| `color.focus` | `#1C1C1C` | 键盘焦点轮廓 |
| `color.overlay` | 柔黑 24% | 模态遮罩，保留背景上下文 |

资源状态示例沿用 G 稿：实心点＋「已启用」、空心点＋「草稿」、短横线＋「已停用」。结果反馈使用勾号＋成功、警示三角＋警告、圆圈感叹号＋错误、信息图标＋说明，并提供具体文案。危险操作使用垃圾桶等语义图标及「删除资源」等明确标签。上述语义角色可以共享墨色色值，不能共享含糊的图标或省略状态文本；禁止默认回退为彩色状态标签。

基础色对的静态计算结果：正文／页面约 16.06:1，辅助文字／表面约 7.07:1，占位文字／表面约 4.56:1，控件边界／表面约 3.79:1。计算基于不透明色值，不代表实际组件验收；透明度、叠层、细字体和禁用状态另行检查。结构分隔线不承担交互边界的对比要求。

暗色属于整库既定范围，但尚无选定暗色稿或已验证数值。T09、T10 和 A23 中延展暖黑／暖灰表面、浅暖文字与同样的单色语义，并在预览中确定色值；H 版不作为暗色基线。不得把浅色 token 机械反相或将暗色适配标为已完成。

## Typography

标题使用 `Georgia, "Songti SC", "STSong", "Noto Serif SC", serif`，保留衬线的阅读气质，以常规字重为主。正文使用 `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。不默认加载远程字体，实际回退、中文覆盖和字宽在支持环境中验证。

| 角色 | 字号／行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 32／40px | 400 | 页面主题，衬线 |
| 弹窗标题 | 24／32px | 400 | Dialog、Drawer，衬线 |
| 分区标题 | 20／28px | 400 | 表格、表单与文档分区，衬线 |
| 正文与数据 | 14／22px | 400 | 内容、表格、菜单、输入 |
| 标签与按钮 | 14／20px | 500 | 表单标签和操作 |
| 辅助说明 | 12／18px | 400 | 元信息、非主要提示 |
| 英文眉题 | 11／16px | 500 | 可选的短编号和栏目名，字距约 0.12em |

衬线不扩散到密集表格、日期数字或表单值。正文数字采用等宽数字排版，金额右对齐；代码示例可用 `"SFMono-Regular", Consolas, monospace`。中文不添加全局字距，不使用全大写规则；错误说明保持至少正文可读水平。英文眉题只是辅助，不能替代中文标题、标签或操作名称。

## 间距、尺寸与密度

以 4px 为基本单位，常用 4、8、12、16、24、32、48px。首版默认采用适合桌面操作的一档密度，以下为规范基线，不提前确定组件属性名称。

| 对象 | 基线 |
| --- | --- |
| 常规控件 | 高 36px；横向内边距 12px；图标 16px；图文间距 8px |
| 小／大尺寸 | 28px／44px 高；在组件规范中说明适用场景 |
| 纯图标按钮 | 默认 36 × 36px，提供可访问名称 |
| 表格 | 行高至少 44px，表头至少 36px；单元格横向 12px，内容增长时允许增高 |
| 树与菜单 | 节点行高至少 36px；层级缩进 16px |
| 表单 | 字段间距 20px；标签与值间距 8px；错误说明占据自然文档流 |
| 页面／分区 | 页面内边距 24—32px；主要分区间距 24px |
| 弹层／弹窗 | 内容内边距 24px；标题、正文和操作分区留白清晰 |
| 边框／圆角 | 常规边框 1px；矩形控件及容器圆角 0 |
| 焦点轮廓 | 墨色 2px，偏移 2px，不能改变布局或被裁切 |

行高和宽度是起点，不强行固定复杂内容的高度。更多数据、长文本或更窄容器通过换行、截断提示及局部滚动处理，不靠缩小整页文字维持 G 稿构图。独立移动端不在本轮规范验收范围内。

## Components

以下规则适用于整库，细节与公共 API 在各组件规范中补齐；当前均未实现。

| 类别 | Editorial 应用规则 |
| --- | --- |
| Button、Link | 主操作墨色实底；次操作细轮廓；轻操作下划线或文字。链接提供持续可辨识的下划线，不仅靠悬停出现 |
| Input、Select、Form | 默认持久标签＋底线输入；搜索、日期范围和组合输入可用完整细边框，保持与 G 稿一致。textarea 用细框。错误说明独立显示，不与占位或浮动标签重叠 |
| Checkbox、Radio、Switch | 方形复选、圆形单选、功能性开关沿用熟悉形状；勾选、半选、开关位置均可辨识，选中不只改变灰度 |
| Table、Tree | 表头保持浅色，细横线分行；选中使用浅暖底＋勾选／侧标记。排序、筛选、半选、禁用和展开有独立图标；密集网格按编辑任务需要增加细线 |
| Date、Time、Calendar | 无衬线数字，墨色块表示所选日期；今天用轮廓／文字标识，范围以浅暖底连接，并明确端点与不可选状态 |
| Upload、Progress | 细虚线拖拽区、文件行和文字进度；失败图标、原因与重试相邻。进度保留数值或文字，不能只靠单色细线 |
| Tag、Badge、Alert | 单色图标＋文字；重要反馈配标题与必要细边界。计数、完成、警告和错误保留不同语义和可访问名称 |
| Dialog、Drawer、Popover | 暖色实底、清晰细框和分区留白，默认无投影。模态使用遮罩；嵌套浮层靠表面、边界和层级区分，聚焦对象始终可见 |
| Tooltip | 柔黑实底、暖白文字，明确触发与退出条件；不承载唯一的错误说明或必须阅读的信息 |
| Empty、Loading | 简单线性图标与可采取的下一步；骨架为平整暖灰块，不做装饰渐变。加载同时提供文字与状态语义 |

组件的线框不能全部只使用低对比的结构色。无投影弹层必须检查相邻表面下的边界；直接沿用原图的微弱线条不构成验收依据。

## 交互状态与组合

| 状态 | 表达 |
| --- | --- |
| 默认 | 控件边界、持久标签与操作名称明确 |
| 悬停 | 加重下划线、切换浅暖底或主操作墨色色阶；不放大、旋转或产生装饰阴影 |
| 按下 | 主操作使用 pressed 色阶；选择控件提供形状反馈，布局保持稳定 |
| 选中 | 浅暖底配勾选、当前标记或端点，持续可识别 |
| 焦点 | 独立墨色轮廓；下划线输入加重底线仍需完整可辨识的键盘焦点 |
| 禁用 | 明确的不可用语义、文字和表面色，阻止交互；不把只读字段当禁用处理 |
| 加载 | 状态文字与进度／旋转指示；阻止重复提交的规则在组件规范中定义 |
| 错误 | 感叹号、具体说明与加重字段线条；维持焦点及修正路径，不依赖彩色 |
| 空与失败 | 说明原因和下一步，保留重试或修改筛选入口 |

禁用决定能否执行；加载决定重复触发策略；错误说明最近一次有效校验结果；焦点在可聚焦控件上独立叠加。错误＋焦点同时保留，不能互相覆盖；禁用＋错误时保留必要的错误说明。受控值、校验时机、异步竞态和最终优先级按组件行为契约明确，不用视觉样式代替状态机。

普通色阶、边框和透明度变化使用 120ms，浮层显隐使用 160ms；信息与提交反馈立即出现，不等待装饰动效。仅在表示加载时使用必要的连续动画；减少动态效果设置下移除非必要过渡、以静态文字保留进度。下划线生长可以作为轻操作反馈，不能推迟可点击性或成为唯一的焦点提示。

## 可访问性与键盘

优先使用原生语义，控件标签、说明和错误必须关联；单色图标不能代替可访问名称。常规有效文字以对比度至少 4.5:1、必要控件边界与状态标记至少 3:1 作为工程检查目标，例外按实际角色记录，不能将来源的合规宣称直接当作本库结果。

选择类组件定义方向键、确认与退出行为。弹层明确焦点进入、关闭、返回及适用的焦点约束；焦点轮廓、错误说明、选中与半选在滚动、缩放、强制颜色及高对比环境下检查。图标按钮提供名称，所有必要操作均应可键盘到达。

## 布局与内容

保留 G 稿的侧栏、筛选、组织树、列表与表单的信息关系，作为组合预览参考，不将列数或图片尺寸固化到基础组件。面板按任务分区，文档使用阅读宽度和章节层级；两者共用 Editorial 视觉语言。

长文本有截断或换行策略，并提供必要的完整查看方式；窄容器中筛选可换行，表格可局部滚动，表单可换列，主要操作和焦点始终可达。预览使用虚构可公开数据，不将资源管理字段写入通用组件默认行为。

## 变量归属与验收

目前角色名及数值以本文为实施依据。T09 将其映射到 `src/tokens/`，实现后实际数值以变量源码为唯一来源，本文维护意图和引用；不得为兼容其他候选再创建一份默认主题规范。变量应覆盖颜色、字体、字号、间距、尺寸、边界、层级和动效，支持单色语义角色独立覆盖。

T10 在运行预览中核对 Button、Input、Select、Dialog、Table、Tree、日期、上传及状态组合，并包含默认、焦点、禁用、加载、错误、长文本、空数据、窄容器和字体回退。灰阶下必须能辨认选择、危险操作和不同反馈；不能仅检查截图外观。

后续以正式变量、真实截图和行为验证形成回归基线。G 图用于方向对照，不能替代真实组件金样、日期逻辑、对比度、键盘或暗色验收；实际结果统一记录在 roadmap。
